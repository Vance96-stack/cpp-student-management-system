# cpp-student-management-system

A simple C++ Student Management System using OOP



\# Student Management System



A console-based Student Management System developed using C++. The program allows users to register students, view student records, search for students using their registration numbers, and automatically assign grades based on their marks.



\## Features



\* \*\*Student Registration:\*\* Add student names, registration numbers, and marks.

\* \*\*View Students:\*\* Display all registered student records.

\* \*\*Student Search:\*\* Find a student using their registration number.

\* \*\*Automatic Grading:\*\* Assign grades based on students' marks.

\* \*\*Interactive Menu:\*\* Navigate through the system using a simple menu-driven interface.



\## Technologies Used

\## How to Run



1\. Clone or download this repository.

2\. Open the project in CodeBlocks or VS Code.

3\. Ensure you have a C++ compiler installed.

4\. Compile the source code.



\### Compile using GCC



```bash

g++ main.cpp -o student\_management

```



\### Run



On Windows:



```bash

student\_management.exe

```
